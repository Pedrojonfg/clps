# Moonpark brand

Small on purpose: a name, a mark, one accent colour.

- **Tagline:** Park where the Sun is.
- **Description:** Landing-site light and Earth-link planner for the lunar south pole.
- **Mark:** a circle (the Moon) crossed by one continuous diagonal with three crossing strokes.

| Token | Hex | Use |
|---|---|---|
| Amber | `#F2A100` | Accent for graphics, buttons, borders, and on dark backgrounds |
| Amber (text) | `#9A5E00` | Text and links on light backgrounds (4.5:1 or better on white) |
| Ink | `#14171C` | Logo and text on light backgrounds |
| Paper | `#F2F4F7` | Logo and text on dark backgrounds |
| Night | `#0E1116` | Dark background, app icon tile |

Files are generated by `python3 branding/make_logo.py`. Do not edit the SVGs by hand.

- `moonpark-mark.svg` / `moonpark-mark-dark.svg`: for light / dark backgrounds
- `moonpark-mark-mono.svg`: single colour (`currentColor`)
- `moonpark-icon.svg`: app icon and favicon (copied to `desktop/public` and `web`)
- `icon-1024.png`: source for `npx tauri icon branding/icon-1024.png` in `desktop/`
- `social-preview.png`: 1280x640 image for GitHub, uploaded in Settings > Social preview
